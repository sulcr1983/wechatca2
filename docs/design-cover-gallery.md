---

## 1. 要解决什么

12 个版式 × 10 套色板 = 120 种组合。如果按组合铺格子，用户会看到
**大量"排版完全一样、只是换个颜色"的重复卡片**，在 120 格里找不到想要的。

> 苏哥原话：「重复内容也要合并显示，譬如不同颜色的，用一个小切换颜色就可以，
> 不用几个显示预览。」

本设计把「版式」作为卡片的身份，把「颜色」降级为卡片内的小切换器。
**一屏 12 张卡，覆盖 120 种组合。**

---

## 2. 三层信息如何映射到界面

`cover-style-spec.md §1` 定义了三层，界面上一一对应：

| 规范层 | 界面元素 | 粒度 |
|---|---|---|
| **视觉体系**（Editorial / Swiss） | 顶栏分段控件，全局切换 | 全局 |
| **版式**（12 个） | 一版式一卡片 | 卡片 |
| **色板**（10 套，体系内 6 / 4） | 卡片底部的小色点 | 卡片内局部 |

关键约束：**色板与体系绑定**（Editorial 只有 6 套杂志色，Swiss 只有 4 套强调色），
所以切体系时，每张卡片的色板要回落到该体系的首推色。

## 3. 卡片结构

```
┌─────────────────────────┐
│                         │
│      3:4 缩略图          │  ← 真实渲染（1080×1440 缩放），不是截图
│      （点击放大）         │
│                         │
├─────────────────────────┤
│ 版式名  [杂志]           │  ← 名称 + 体系标签
│ ● ● ● ● ● ●   沙丘暖纸   │  ← 色点（悬停出名字）+ 当前色名
└─────────────────────────┘
```

### 3.1 缩略图必须是真实渲染，不是图片

- 用真实 DOM 渲染 1080×1440，再 `transform: scale()` 缩到卡片宽度
- 换色只改 `data-theme` 属性 → CSS 变量重算，**不重建 DOM**
- 好处：换色零延迟；不会出现"截图配错了颜色"的问题

### 3.2 色点交互

| 动作 | 行为 |
|---|---|
| 悬停色点 | 显示色板名（tooltip），不改变预览 |
| 点击色点 | 该卡片换色，色点加环，下方色名文字更新 |
| 点击缩略图 | 打开放大预览（含该版式的首推色板列表） |

**不做悬停即换色**：鼠标划过 6 个点会让预览闪烁，反而看不清。

### 3.3 放大预览

- 左侧：该组合的完整渲染（按视口高度定尺寸）
- 右侧：版式名、说明、体系、版式 ID、当前色板、画板尺寸
- 底部：首推色板 2–3 个（可直接点切换，同步回卡片）

## 4. 为什么不是「按色板分组」

另一种可能的组织方式是「以色板为主、版式为切换器」。不采用，理由：

1. **色板是情绪，版式是结构**。用户找模板时想的是"我要清单还是大字报"（结构），
   不是"我要墨色经典"（情绪）。结构是主检索维度。
2. 同一色板下 12 个版式的差异巨大，很难在一屏里横向比较；
   同一版式下 6 个颜色的差异很小，正好适合用点切换。
3. `style-system.md:32` 规定色板不能随意新增（6 套杂志色是官方预设），
   色板不是增长维度，**版式才是**。主维度应该给增长维度。

## 6. 版式差异度：加版式最容易翻车的地方

原型第一版交付后，发现两个严重问题，记录在这里当检查项：

### 6.1 大字报 ≈ 堆叠

两个版式都渲染成"2 行标题 + 底部副标"，缩略图里几乎一样。

**根因**：语义断行会压低字号，两个版式的基准字号差异（128 vs 108）
被断行逻辑抹平了，最终都落在 119–136px。

**修法**（两选一）：
- A. 放大基准 + 缩小左右边距（`poster` 用 60px 边距，可用宽 888 → 960）→ 152px
- B. 允许 3 行 → 169px，但会把「个工具」切成孤行

**采用 A**。判定标准：两个版式的标题字号差 **≥ 20%** 才算区分开。

### 6.2 清单 ≈ 步骤

都是"编号 + 标题 + 说明"的竖向列表。

**修法**：
- 清单：编号用**衬线大号**（40px），靠字形区分
- 步骤：改成**时间轴**（贯穿竖线 + 圆点），靠结构区分

### 6.3 通用检查项（加任何新版式都要过）

1. 与已有版式的**标题字号**差 ≥ 20%，或
2. 有**独有的结构元素**（时间轴 / 网格 / 分栏 / 超大数字 / 引号）
3. 缩略图（约 240px 宽）下，与相邻版式**一眼可辨**
