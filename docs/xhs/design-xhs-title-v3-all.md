> **状态**：2026-11-06 项目所有者拍板 —— 选定 v3 方案 1（三栏常驻），并要求**版式全量可见、不删不藏**。
> **本文是什么**：标题图模块的目标设计真源（信息架构 / 按钮 / 状态 / 输出 / 验收）。
> **不是什么**：不是实施进度表，不是测试报告；版本、构建号、门禁结果一律看 `STATE.md`。
> **原型**：`docs/prototypes/xhs/v3/concept-a-three-col.html`（交互版，上传一张图即可看到 30/30 套）
> **实测快照**：`output/prototypes/v3-concept-a-all-30.png`（本机 1600×1000 实拍，gitignore 产物）
> **取代关系**：
> - 取代 `design-xhs-studio-final.md` 的「26 套 / 三栏 236·684·520」口径（版式数量与可见性规则）；
> - 取代 `design-xhs-canvas-ux.md` 的「单画布」方向（C-1 已裁定为三栏常驻）；

## 0. 一句话方案

**左写、中看、右换；右栏一次铺满 30 套版式，不按“有没有图”隐藏模板。**

三栏常驻，不弹窗；版式切换、配色切换、字体切换都在一屏内完成。模板数量按“越多越好”处理：**30 套全部出现在右栏**，当前不能用的版式置灰并给出原因，而不是从列表里消失。

## 1. 范围

### 1.1 本期包含

- 标题图页面（`pwa/src/cover/` 的标题图 Tab）的骨架、控件、状态、输出。
- 30 套版式（7 套现有 + 23 套配方）在右栏的全量呈现与选择。
- 三种尺寸、九宫格、保存 PNG、复制富文本、历史记录。
- 桌面三栏与窄屏三页签（文案 / 画布 / 样式）的响应式规则。

### 1.2 本期不包含

- 长图文模块（`longform-page.js`）的版式与输出；它有自己的 `requirements-xhs-longform.md`。
- 公众号排版模块（`core/format_engine.py` 等）。
- 服务端能力：标题图仍然是**纯前端生成**，不上传文案与图片，不引入后端存储。
- AI 生成封面图；标题图不依赖 AI。

## 2. 信息架构与布局

### 2.1 三栏骨架

| 区域 | 宽度（≥1281px） | 内容 |
|---|---|---|
| 顶栏 | 56px 高 | 品牌 / 模块切换 / 本地排版标识 / 历史 / 保存大图 |
| 左栏 | 236px | 文案、配图、尺寸、署名、可读性、贴士 |
| 中栏 | `1fr`（1440 下约 684px） | 画布、状态条、复制 / 九宫格 / 保存 |
| 右栏 | 520px | 版式 30 套、密度、配色、字体、玩法、位置 |

- 画布按高度约束：3:4 在 1440×900 下约为 567×756；不允许为了填满中栏把画布拉大。
- 三栏都是常驻区域，不使用右侧抽屉承载版式；「全部版式」只是 30 套的放大浏览入口，不是唯一入口。
- 页面**不设“标题图结果”画廊**：画布本身就是结果，保存后走出片托盘；同一张图不在页面上展示两次。

### 2.2 响应式断点

| 视口 | 行为 |
|---|---|
| ≥1281px | 236 / 1fr / 520，右栏 5 列版式卡（30 套需滚动） |
| 980–1280px | 左栏收窄、右栏 420px，版式 4 列 |
| <980px | 三栏折成三个页签：文案 / 画布 / 样式；底部固定操作条；画布单列 |
| 375px | 不允许横向溢出；版式卡可横向滚动，不压缩到不可点 |

## 3. 左栏：输入与素材

### 3.1 文案

| 控件 | 行为 |
|---|---|
| 多行输入框 | 最多 500 字；**第一行 = 大标题**，第二行起 = 小字/副标题，最多 3 行参与排版 |
| 字数计数 | 实时显示 `已输入 / 500`；超限截断并 toast |
| 「用正文」 | 把公众号编辑器正文首段带入标题图；无正文时置灰并提示 |
| 「示例」 | 填入固定示例文案（用于验收与首次体验） |
| 「清空」 | 清空文案与画布，回到空态；不删除已选配图与版式 |

规则：

- 标题为空时画布显示空态「左边写一句话」，保存/复制/九宫格按钮禁用。
- 标题过长时自动缩字号；不截断文字。缩到下限仍放不下时，画布内换行，不溢出。
- 小字按 `·` / 换行拆条；清单类版式至少 2 条才可用。

### 3.2 配图

三个互斥模式（`aria-pressed`）：

| 按钮 | 行为 |
|---|---|
| 搜图 | 打开搜图弹层；关键词从标题自动提取，可改；Pexels 单源，需要用户自己的 Key |
| 传一张 | 打开本地文件选择；支持 JPG/PNG/WebP；上传后立即成为当前底图 |
| 不要图 | 清空底图，回到纯色/纯文字；需要图的版式置灰但保留 |

当前底图卡片：

- 缩略图 + 文件名/来源 + 「换一张」「去掉」。
- 搜图来源显示 `Pexels · 作者 · 许可`；上传显示文件名。
- 底图可读性条：按底图亮度给出“文字压得住/压不住”，必要时建议加磨砂；不阻断生成。

搜图弹层：

- 关键词输入 + 搜索按钮 + 6 张候选网格。
- 无 Key：不弹空白，直接给「填 Key」指引与上传入口。
- 无结果 / 网络失败 / 图片加载失败：给明确原因，允许改用上传。
- 原型用本地 6 张示例图；落地接 Pexels（BYOK），不把示例图当真实搜索结果。

### 3.3 尺寸

| 尺寸 | 像素 | 用途 |
|---|---|---|
| 3:4 | 1080×1440 | 小红书主图（默认） |
| 1:1 | 1080×1080 | 方图 |
| 21:9 | 2100×900 | 横版 |

切换尺寸只改变画布与导出，不重置版式/配色/文案。

### 3.4 署名与贴士

- 署名最多 16 字，可留空；显示在画布固定位置，不参与标题缩字号。
- 贴士折叠区：第一行大标题、7 字最易排、清单至少 2 条；默认收起，不占首屏。

## 4. 中栏：画布与出片

### 4.1 画布

- 画布内容由当前版式 + 配色 + 字体 + 玩法 + 位置 + 底图共同决定。
- 画布下方显示：尺寸（如 `1080 × 1440`）、版式名、底图可读性（有图时）。
- 画布不显示“实时预览/结果”两份；只有这一张。

### 4.2 操作条

| 按钮 | 行为 | 禁用条件 |
|---|---|---|
| 复制 | 把画布转成富文本 HTML 写入剪贴板；toast 说明可直接粘进公众号 | 标题为空 / 渲染未完成 |
| 九宫格 | 打开九宫格弹层，按 3×3 切图 | 标题为空 / 当前尺寸不支持 |
| 保存大图 | 生成当前尺寸 PNG；弹出出片托盘 | 标题为空 / 渲染中 |

### 4.3 出片托盘

保存后从底部出现，包含：

- 缩略图（当前画布）
- 尺寸 / 格式 / 估算大小 / “纯前端生成”
- 「复制」「下载 PNG」「关闭」

同一张图不重复放到页面画廊；托盘关闭后仍可从历史记录找回。

## 5. 右栏：版式与样式

### 5.1 版式区

- 标题：`版式 30 套`；右侧「全部 ↗」打开放大浏览。
- 密度：5 列 / 4 列两档；默认 5 列。30 套一次铺开，允许纵向滚动。
- **所有 30 套始终显示**；不因“没选图”而隐藏。不能用的版式置灰，卡上给原因（如需底图 / 清单要 2 条），点击时 toast 说明并给快捷入口（去选图）。
- 每张卡：缩略图 + 名称 + 配方编号（有则显示）+ 需要底图标记。

- **30 套 = 现有 7 + 配方 23**。

> 不占这 30 套的名额；入口在中栏常驻，输入是当前画布产物或用户上传的图片，与「选哪套版式」无关。
> `catalog.js` 里遗留的 `nine-*` styleId 只作旧偏好回落，**不再作为版式卡出现在右栏**。
> 代码落点：`pwa/src/cover/layout-registry.js` 显式排除 `nine`（导出 `NINE_LAYOUT_ID`），
> 注册表断言 `scripts/cover_registry_unit.mjs` 守住这条口径。

### 5.3 「全部版式」弹层

- 30 套以更大的卡（约 1180px 宽）展示，供快速对比气质。
- 点击即选中并关闭弹层；不改变当前配色/字体。
- 与右栏共用同一份清单与选中状态，不另造第二套数据。

### 5.4 配色

- 配色是**版式的属性**，不是全局开关：每套版式只显示它支持的 3–10 个色板。
- 切换版式时保留同名色板；目标版式没有该色板时回落到该版式的第一个。
- 不做“全局 23 色随便套”的假自由，避免每套版式失去自己的气质。

### 5.5 字体

原型提供 10 款：跟随版式、黑体、宋体、得意黑、文楷、快乐体、小薇、马善政、龙藏、志莽。
**当前产品只有 4 款**（跟随/思源黑/思源宋/得意黑）；首期落地 4 款，其余 6 款作为后续增强，不在本期偷偷删原型选项。

### 5.6 玩法 / 位置

| 控件 | 选项 | 说明 |
|---|---|---|
| 玩法 | 默认 / 大字 / 竖排 / 错位 / 变色 / 描边 / 错行 | 只影响标题排法，不改变文案 |
| 位置 | 自动 / 上 / 中 / 下 | 自动按底图亮度与版式决定 |
| 磨砂 | 开 / 关 | 仅图文版式；给底图加半透明遮罩，提高文字可读性 |

## 6. 输出契约

### 6.1 PNG

| 项 | 规则 |
|---|---|
| 触发 | 中栏「保存大图」/ 顶栏「保存大图」 |
| 尺寸 | 当前选中尺寸：1080×1440 / 1080×1080 / 2100×900 |
| 格式 | PNG，2× 渲染后按目标尺寸输出（避免文字发虚） |
| 文件名 | `xhs-title-<yyyyMMdd-HHmmss>-<layout>-<size>.png` |
| 失败 | 不静默：toast 说明失败原因（字体未就绪 / Canvas 被污染 / 浏览器拒绝下载）并提供重试 |

### 6.2 九宫格

| 项 | 规则 |
|---|---|
| 入口 | 中栏「九宫格」 |
| 切法 | 方形居中裁剪后 3×3；顺序 1→9（可切蛇形） |
| 单张 | 3:4 → 360×480；1:1 → 360×360；21:9 → 700×300 |
| 打包 | ZIP，内含 `nine-01.png` … `nine-09.png` |
| 空白预警 | 逐格统计内容覆盖率；≥3 格接近空白时提示「把标题放大铺满」；不阻断下载 |
| 失败 | ZIP 生成失败给原因；不允许只下载部分且不说明 |

### 6.3 复制富文本

- 写入 `text/html` 到剪贴板，保留内联样式与图片（能内嵌则内嵌）。
- 成功 toast：「已复制，去公众号后台粘贴」；失败给原因（浏览器不支持 / 权限被拒 / 图片未本地化）。
- 不把 base64 图片直接写进 `text/plain`，避免粘贴出乱码。

### 6.4 历史记录

- 入口：顶栏 `↺`（方案 1 原型）；每次保存大图后记录一条。
- 存储：`localStorage`，键 `supersu.cover.history.v1`，最多 24 条，按时间倒序。
- 每条包含：版式、配色、尺寸、标题、时间、可恢复的画布快照。
- 刷新不丢；清空浏览器数据即清空，不做云同步。
- 已知取舍：顶栏图标的发现性弱于命令栏常驻「历史 N」；本期按方案 1 原型落地，若上线后实测发现性不足，再评估把入口移到操作条。

## 7. 状态与失败恢复

| 场景 | 行为 |
|---|---|
| 标题为空 | 画布空态；复制/九宫格/保存禁用；不报错 |
| 无底图 | 20 套纯文字可用；10 套需图版式置灰并提示「这套要一张底图」，点击给「去选图」 |
| 清单不足 2 条 | 清单版式置灰并提示「清单要 2 条以上小字」 |
| 搜图无 Key | 直接显示填 Key 指引 + 上传入口，不空转 |
| 搜图无结果 | 显示「没搜到，换个词或上传自己的图」 |
| 图片加载失败 | 明确坏图，允许重选；不把坏图当成功 |
| 字体未就绪 | 画布先出近似结果并标「字体加载中」；保存按钮等字体就绪后才可用 |
| 渲染失败 | 画布保留上一次成功结果，toast 说明原因；不静默清空 |
| 保存/下载失败 | toast 给原因 + 重试；历史不写入失败记录 |
| 九宫格空白 | 黄条预警 + 「把标题放大铺满」快捷修复；仍允许下载 |
| 本地存储不可用 | 收藏/历史降级为内存态，并 toast 说明刷新会丢 |

统一原则：**每个等待有反馈，每个降级说明原因，不静默失败。**

## 10. 与现状的差距（落地前必须知道）

| 项 | 现状（产品代码） | 目标（本文） | 差距 |
