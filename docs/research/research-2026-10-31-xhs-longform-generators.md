# 小红书长图文生成器 —— 竞品实际形态调研

> 调研日期 **2026-10-31**
> 调研对象：**真实在运营的生成器产品**（不是设计理论文章）
> 目的：确认「一套图文」的正确结构，避免自己拍脑袋设计

---

## 一、为什么要做这次调研

项目里对长图文反复返工过两次：

1. 第一版：只按内容形态分页（开篇/清单/金句/正文），一套 4–10 页，**无上限、无封面概念**
2. 第二版（错）：把标题图的 12 套视觉模板套到**每一页**，并让用户分别选「封面版式」和「内页风格」

第二版被用户当场否掉：

> 「假如是长图长文的第一页和其他页完全不同，也很奇怪啊。」
> 「我让你去调研是去调研人家小红书生成器是怎么做的。」

于是去读了真实产品的**编辑器界面**与**API 文档**，而不是设计博客。

---

## 二、核心结论（先看这个）

> **「模板」是整套图文共用的一个东西，不是每页各选一个。
> 封面不是「选版式」的地方，它只是这套模板下的一个可选附加页。**

这条直接否定了第二版的做法。

---

## 三、证据：XHS-TextCard 编辑器的实际结构

来源：https://xhs-textcard.site/editor.html（2026-10-31 抓取）

它的「模板与设置」是一个**三 Tab 面板**，而不是两个独立选择器：

```
模板与设置
├─ 【内页】Tab
│   ├─ 内页模板          ← 12 套模板选一个（整套生效）
│   ├─ 页面比例          ← 3 种，切换会重新分页
│   ├─ 内页背景图片      ← 「图片将全屏铺满所有内页」
│   ├─ 排版基础          ← 字号 14 / 行高 1.7 / 字距 0.5 / 内边距 40
│   ├─ 标题层级          ← H1 2x / H2 1.35x / H3 1.15x
│   ├─ 字体族            ← 9 种
│   └─ 颜色风格          ← 背景渐变色 + 正文色 + 强调色（全局）
│
├─ 【封面】Tab
│   ├─ 启用封面          ← 一个开关
│   ├─ 封面图片          ← 上传 / 随机图片（「默认随机背景」）
│   ├─ 封面字号          ← 48px
│   └─ 社交图标          ← 位置：右上角 / 底部居中
│
└─ 【导出】Tab
```

### 三个关键观察

1. **内页模板 12 选 1，但只有一个选择器** —— 没有「封面版式」这一项。
2. **封面 Tab 里没有「版式」概念** —— 只有「启用封面」「封面图片」「封面字号」「社交图标」。
   也就是说：**封面 = 内页模板的第 1 页 + 一张背景图 + 一个开关**。
3. **颜色风格是全局一套** —— 背景/正文色/强调色不区分封面与内页。

### 官方文档的旁证

来源：https://xhs-textcard.site/guide

> `"template" 和 "config"` —— 保持从编辑器复制过来的原值不动，
> 它们决定了最终排版使用**哪个模板和哪套样式参数**。

API 只有一个 `template` 字段（`blank` / `polaroid` / `notion-style` / `elegant-book` /
`ios-memo` / `swiss-studio` / `minimalist-magazine` / `aura-gradient` / `deep-night` /
`pro-doc` / `cinematic-film` / `starry-night`），**不是每页一个**。

## 四、旁证：设计侧的两条通用原则

虽是设计文章而非产品文档，但对「同族」这件事说得最直白。

### CreatorFlow《Instagram Carousel Posts: Templates, Sizes & 12 Tips》

> **Use Consistent Visual Branding** — Users should recognize your carousels instantly.
> - **Same color palette across all slides**
> - Consistent font pairings (max 2 fonts)
> - **Repeated design elements (borders, icons, shapes)**
> - Branded watermark or logo (small, corner placement)

### Dhia Portfolio《Social media visual consistency》

> **One template family, not fifty one-offs.**
> Consistency doesn't mean boring. It means you repeat the same visual rules while changing
> the content. **Same type hierarchy, same color roles, same spacing rhythm, same photo
> treatment. The topic changes; the system stays.**

### Carousel Maker（商业产品，100+ 模板）

> **Keep every post on brand** — "Change a style once and **update the full carousel in one go**."

## 五、对我们的含义（直接对应到代码）

| 错误做法（第二版） | 正确做法（按竞品） |
|---|---|
| 两个选择器：封面版式 + 内页风格 | **一个选择器：模板**（整套生效） |
| 封面选 C1 全出血，内页选杂志编辑 → 风格断裂 | 封面 = 这套模板的 P1，内页 = P2~N |
| 12 套模板里挑 5 套当内页风格 | 12 套就是 12 套，**每套都要能同时排出封面和内页** |
| 封面是版式选择的结果 | 封面是「启用封面」开关 + 背景图 + 字号 |
| 拍立得/电影胶片「不能做内页」被排除 | 它们本来就该能连排多页 —— 竞品就是这么用的 |

### 与「标题图」的边界（不要混）

| | 标题图 | 长图文 |
|---|---|---|
| 产出 | **1 张**封面 | **1 套**（封面 + N 张内页） |
| 版式 | 12 种封面版式（C1–C6 / T1–T6），**是标题图专属** | 12 套图文模板，**是长文专属** |
| 底图 | 搜图作底图，参与压暗判定 | 内页「背景图片将全屏铺满所有内页」；封面图片可上传/随机 |
| 复用关系 | — | **不复用标题图的版式** |

> 用户原话：「至于背景图那是搜图模块增加的功能，和版式不同啊！」
> —— 这句话点明：**背景图是「图」这一维度，版式是「排版」这一维度，两者正交。**

## 六、尚未确认的点（后续若要更像竞品）

1. **页面比例**：竞品给了 3 种（小红书长文 500×750 / 小红书 3:4 500×667 / 短视频 9:16 500×889），
   标注「每种比例使用固定画布和固定文字区域，切换后会重新分页」。我们目前是 3:4 / 1:1 / 21:9。
2. **内页背景图**：「图片将全屏铺满所有内页」—— 竞品支持给内页铺背景图，但**不参与压暗判定**，
   等于纯装饰。我们当前内页是纯色。
3. **强制分页符**：`---` 独立成段即可强制分页。我们把 `---` 当分隔线处理，语义不同。
4. **水印 / 签名栏 / 网格辅助线 / 页码**：竞品都在「高级设置」里给了开关。

这些都不影响本轮的结论（模板是整套的），列为后续可选增强。
