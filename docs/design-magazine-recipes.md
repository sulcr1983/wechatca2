# 杂志风版式配方库（2026-11-01）

> **这是方案，不是实现。** `core/`、`pwa/src/` 一个字没改。
> 来源：用户提供的 14 张截图 + 复制文字，全部是「优秀公众号排版拆解」的二手配方，
> 我逐条 OCR 整理成可执行参数。**每家都记了「为什么这么设计」，不是只抄数值。**
>
> 配套：`design-layout-system-v3.md`（三层模型）、`research-2026-11-01-seneasy-72-layouts.md`（72 套实证）

## 0. 一句话

这批配方和句方便那 72 套**互补**：

| | 句方便 72 套 | 这 14 套配方 |
|---|---|---|
| 侧重 | 标题**局部装饰**（眉标/编号/装饰线） | 整篇**版式气质**（框线/留白/分区/节奏） |
| 单位 | 一套主题 = 一套配色+结构 | 一套配方 = 一种**报刊/品牌的设计语言** |
| 可复用性 | 主题内绑定 | **参数化**：换肤色即可复用 |

这批的价值在于：它们讲清了「为什么好看」，而不是「长什么样」。

## 2. 逐套配方（含参数与理由）

### 2.1 时代周刊 Time

**三个特点**：红色框线、居中秩序、小信息。

| 参数 | 值 |
|---|---|
| 正文 | 16px / 行距 1.75 / 段后 14px |
| 一级标题 | 24px |
| 二级标题 | 20px |
| 小信息（人物·日期·栏目·关键词） | 比正文小一号，灰色或红色 |
| 图注 | 比正文小一档，浅灰 |

**手法**：
- 红色**不铺满**，只做：细框线、标题线、序号、小标签
- **重点结论外面加一圈细红框** ← 最出效果的一条
- 开头单独设计：栏目名置顶 → 主标题居中 → 短导语 → 多留白
- 整篇白底黑字

**为什么**：靠「框线 + 留白 + 信息层级」形成特点，不靠装饰。

---

### 2.2 卫报 Guardian

**四个参数**：

| # | 参数 | 值 |
|---|---|---|
| 1 | 大标题上方 | 先压一行 14px **红色小字**写「观点」，下面才是 28px 深蓝大标题（报纸叫「眉题」） |
| 2 | 三种颜色各管一件事 | 深蓝管标题、红色只做记号、亮黄留给高亮 |
| 3 | 线只用一像素浅灰 | 二级标题顶压一根；前面再放 10px 红色小方块；分隔线**干干脆脆两根，中间只隔 3px** |
| 4 | **引用放大** | 正文 16px，引用 **19px + 加粗 + 深蓝**，不加框不加底，只在头上放 44px 红色引号 |

**为什么反直觉**：引用通常缩小，这里**放大 3px** ——「读者往下划，最先停住的就是这一句」。

---

### 2.3 国家地理 National Geographic

**核心思路：招牌黄用得越少越像** —— 黄色只做线，不做底。

| # | 参数 | 值 |
|---|---|---|
| 1 | 二级标题加黄色编号 | 编号 **22px**，左边一道 **4px 粗线**、右边一道 **1px 细线**，像杂志页码 |
| 2 | 分隔线只画 **52px** | 3px 粗，不到手机屏宽七分之一，比整条横线更自然（暗示「换个话题了」） |
| 3 | 引用不加框 | 浅灰底 + 左边一道 4px 黄线 + 上方一枚 **28px 黄色引号**，字体比正文小一号（15px） |
| 4 | 高亮不用黄底 | 底是浅灰，黄色只在**字下面垫一条 2px 的线**，链接也只加黄线 |

---

### 2.4 经济学人 The Economist

**核心思路：少即是多。**

| 手法 | 参数 |
|---|---|
| 红色只画线 | 标题上方一道红条、小标题前红色序号、引文左边红竖线 |
| 正文 | **深灰非纯黑**，16px，行距 1.75 |
| 小标题 | 左对齐、无图标、**18px**，前面带红色「01」「02」序号，下面一条浅灰细线 |
| 重点句 | **22px 加粗 + 左边一条红线 + 不加底色** |

**为什么**：铺底色反而显廉价。

### 2.5 无印良品 MUJI

| 项 | 值 |
|---|---|
| 背景 | 米白 `#F8F6F1`（不用纯白） |
| 正文 | 暖深灰 `#3D3935`（不用纯黑），**16px / 行距 1.8 / 字距 0.5px** |
| 段落 | 每段控制在 **2–4 行**，留出明显空隙 |
| 小标题 | **19px 加粗**，前缀酒红色序号（01、02…），下方一条很浅的细线 |

| 引用 | 铺一块浅米色底 `#EFEAE1`，**不用左侧竖线** |
| 图片 | 不要圆角、不要边框、不要阴影，前后留足空白 |
| 图注 | 浅灰小字，一句话就够 |

**强调色**：低饱和酒红 `#7F0019`，**只用于序号、小方块等极小范围**。

### 2.7 浮世绘 Ukiyo-e

**三个特点**：米灰宣纸底、点睛赭红、版画印章感。

| 项 | 值 |
|---|---|
| 正文 | **17px / 行距 1.8 / 段间距 20px**，衬线宋体，不用纯黑，选深青灰，两端对齐 |
| 底色 | 米灰宣纸色（不用纯白） |
| 标题 | **24px 加粗**，米灰宣纸色字 + **深靛蓝底色块** + 右下角 **赭红硬阴影** |
| 重点结论 | 深靛青底 + 纯白提亮 + 四周加细线条 + 右下角**叠一层赭红实心阴影** |
| 关键词 | 不用荧光划线，直接加粗换赭红 |

**注意**：这里的阴影必须是**硬阴影**（无模糊），才有「刚盖上去的印章」感。

### 2.8 Vogue 画报

**整篇只用黑和白，一种彩色都没有。**

| # | 手法 | 参数 |
|---|---|---|
| 1 | 大标题 | **34px 宋体，粗到最粗**；下面压**两根线，一粗一细**（单根只是分割线，一粗一细叠在一起就成了杂志的「看头」） |
| 2 | 二级标题 | **23px**，前面放一个 **52px 的斜体数字**（数字比标题大一倍多） |
| 3 | 正文 | 16px，行距 1.9；图片**铺满整行、不加圆角**；图注换成**十二号小字**，头顶压一根细线 |
| 4 | 重点 | **不上色**，只在下面**垫一道细线** |

**为什么反直觉**：「真正要高潮的，直接反白，黑底白字。没有颜色抢戏，读者的眼睛反而只落在你想让他看的地方。」

### 2.9 福布斯 Forbes

**三个特点**：大数字、强标题、人物和数据组合。

| 项 | 值 |
|---|---|
| 正文 | **16px / 行距 1.7 / 段后 12px** |
| 一级标题 | 26px |
| 二级标题 | 19px |
| **大数字** | **28–32px**，配一句很短说明 |

## 3. 横向归纳：这 15 套共同遵守的 6 条规律

这是比单套参数更有价值的部分 —— **它们是「好看」的底层原因**。

### 规律 1：强调色**只做线/标签，不铺底**

| 配方 | 怎么做的 |
|---|---|
| 时代 | 红色只做细框线、标题线、序号 |
| 卫报 | 红色只做记号 |
| 国家地理 | 黄色只画线，不做底 |
| 经济学人 | 红色只画线，铺底显廉价 |
| 宜家 | 黄色只画线垫底，一个字都不写 |

> **只有森系和浮世绘例外**：它们把色块用在**标题**上（书签/印章），因为那是「材质感」而不是「强调」。

### 规律 2：正文永远 16–17px，行距 1.7–1.9

| 配方 | 字号 | 行距 | 段后 |
|---|---|---|---|
| 时代 | 16 | 1.75 | 14px |
| 卫报 | 16 | — | — |
| 经济学人 | 16 | 1.75 | — |
| 无印良品 | 16 | 1.8 | — |
| 森系 | 16 | 1.8 | 20px |
| 浮世绘 | **17** | 1.8 | 20px |
| Vogue | 16 | **1.9** | — |
| 福布斯 | 16 | 1.7 | 12px |
| 星巴克 | 16 | 1.75 | 14px |
| 阿迪达斯 | 16 | 1.7 | 12px |
| 新粗野 | **17** | 1.6 | — |
| 笔记纸 | 16 | **1.9** | 16px |
| 深度阅读 | **17** | 1.85 | — |

> **和我们现状的对比**：我们 164 套统一 15px / 1.75–1.9。
> 这批配方几乎全部用 **16–17px** —— 我们偏小了一号。

### 规律 3：标题层级梯度是 24/20 或 26/19

| 配方 | 一级 | 二级 | 梯度 |
|---|---|---|---|
| 时代 | 24 | 20 | 4 |
| 经济学人 | — | 18 | — |
| 无印良品 | — | 19 | — |
| 森系 | — | 20 | — |
| 福布斯 | 26 | 19 | 7 |
| 星巴克 | 24 | 20 | 4 |
| 阿迪达斯 | 25–27 | 19 | 6–8 |
| 宜家 | 24 | — | — |
| 深度阅读 | 26 | 22 | 4 |
| Vogue | 34 | 23 | 11（特例，靠双线加持） |
| 新粗野 | 36 | 28 | 8（特例，色块加持） |

> **注意**：除 Vogue/新粗野这两个「视觉冲击型」，**其余全部落在 24–26 / 19–20**。
> 这是一个非常集中的区间 —— 说明正文 16px 时，标题 24/20 是「最稳」的比例。

### 规律 4：**反直觉的四条**（最值得抄）

| 反直觉 | 为什么 |
|---|---|
| **引用放大而不是缩小**（卫报 16→19px） | 「读者往下划，最先停住的就是这一句」 |
| **重点句放大而不是变小**（经济学人 22px） | 变小 = 次要；变大 = 主次分明 |
| **重点不上色，只垫一条线**（Vogue） | 没有颜色抢戏，眼睛才落在你想让他看的地方 |
| **分隔线只画 52px**（国家地理） | 短一截比整条横线更自然，暗示「换个话题」 |

### 规律 5：图注是「编辑感」的关键

| 配方 | 图注处理 |
|---|---|
| 时代 | 比正文小一档，浅灰 |
| 无印良品 | 浅灰小字，一句话就够 |
| Vogue | 十二号小字，头顶压一根细线 |
| 阿迪达斯 | 图片上下多留空间，别让文字挤在一起 |

> 我们 164 套里只有 `convert_image_captions` 一处处理图注，且只调颜色。

### 规律 6：留白靠「段距 + 分区」而不是空行

| 配方 | 手法 |
|---|---|
| 星巴克 | 米白做分区，把留白拉开一点 |
| 无印良品 | 每段控制 2–4 行，留出明显空隙 |
| 森系 | 段后 20px |
| 笔记纸 | 段间距 16px |

## 4. 落到我们产品上：怎么加

### 4.1 关键决策：**这些是「版式」，不是「主题」**

这是本方案最重要的一条。

| | 主题（Theme） | 版式（Layout） |
|---|---|---|
| 决定 | 颜色、字体、行距 | **结构、框线、分区、节奏** |
| 数量 | 164 套 | 现在 8 个 → 目标 23 个 |
| 用户选 | 常换（选皮肤） | 常换（选骨架） |

**理由**：这 15 套配方里，**颜色几乎全部是「从强调色派生」**（红色只画线、黄色只画线、豆绿只做书签）。
所以它们能和任意一套现有主题组合 —— 用户在「墨韵」上选「时代周刊」，会得到黑白的时代周刊版式；
在「钢印·朱砂」上选，会得到朱砂线的时代周刊。

**这正好符合你已经拍板的「版式 × 配色」二维模型。**

### 4.2 不建议做的事

| 不建议 | 原因 |
|---|---|
| 把 15 套做成 15 个固定配色的新主题 | 那就退化成「只换颜色」，而且和现有 164 套重复 |
| 照抄截图里的具体色值（如 `#0058A3`、`#FFDA1A`） | 那是宜家的品牌色。**我们只抄手法，不抄色值**（与项目既有版权路线一致） |
| 一次全上 15 套 | 建议按「规律」分批：先上 4 条反直觉的，见效最快 |

### 4.3 建议的落地优先级

| 批次 | 配方 | 理由 |
|---|---|---|
| **第一批（4 套）** | 时代周刊 / 卫报 / 经济学人 / Vogue | 覆盖 4 条反直觉手法，且都是纯线框（改动最小、风险最低） |
| **第二批（4 套）** | 国家地理 / 福布斯 / 无印良品 / 森系 | 加入「大数字」「底块标题」两个新维度 |
| **第三批（4 套）** | 浮世绘 / 新粗野 / 笔记纸底 / 宜家 | 引入「硬阴影」「网格底」「双色分工」 |
| **第四批（3 套）** | 星巴克 / 阿迪达斯 / 深度阅读 | 收尾（风格与前三批有重叠） |

### 4.4 和我们已有能力的关系

| 已有 | 状态 |
|---|---|
| 现有 8 个版式 | **全部保留**，不删不合并（见 `design-layout-system-v3.md` §4.1） |
| 三层模型（皮肤/钩子/版式） | 这 15 套属于**第三层「版式」** |
| 钩子（kicker/titleMark/h2Badge） | 这 15 套里有 8 套用到了钩子（眉标、编号徽标） |
| 164 套主题 | **一个字不改**，作为「皮肤」被复用 |

## 5. 需要注意的冲突点（提前说清）

| 冲突 | 说明 | 建议 |
|---|---|---|
| **行高** | 这批配方用 1.7–1.9，我们主题 JSON 里锁死 1.75–1.9 | 版式层可以覆盖行高，但**默认值不动**（不改现有 164 套的产物） |
| **字号** | 这批用 16–17px，我们统一 15px | 同上：版式层可覆盖，主题默认不变 |
| **「只画线不铺底」vs 我们现有的色块标题** | 我们 56 套 h2 是实心色块 | 不冲突：那是**主题**的属性；选了这个版式后，版式层会把 h2 改成线框（这是用户主动选的结果） |
| **硬阴影** | 微信对 `box-shadow` 支持良好（已实测），但**不支持 `filter: drop-shadow`** | 只能用 `box-shadow`，且必须给 `rgba` 色值不用透明度变量 |
