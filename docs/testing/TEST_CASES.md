### 1.2 用户主流程（端到端）

**流程 A：公众号排版（核心）**
```
打开页面 → 等引擎就绪 → 粘贴纯文本 → 自动识别结构（400ms 防抖）
→ 选主题（色卡 / 抽屉）→ 预览实时更新 → 点「复制到公众号」
→ 粘贴到公众号后台（富文本保留样式）
```
依赖链：引擎就绪 → 主题 JSON 加载 → 渲染 → 剪贴板写入。
**任一处断，用户的主要目的就达不成。**

**流程 B：导出分发**
```
有排版结果 → 导出 ▾ → 长图 PNG / HTML / Markdown / 图片 ZIP → 浏览器下载
```

**流程 C：小红书封面**
```
顶部「小红书标题图生成」→ 封面页 → 写文案 → 选版式/配色/尺寸
→ （可选）选底图 → 实时预览 → 保存大图 / 整套图文 → 打包 ZIP
```

**流程 D：草稿与偏好持久化**
```
输入内容 → 500ms 防抖存 localStorage → 刷新/重开 → 自动恢复
```

### 1.5 易出边界 / 一错影响全局的功能

| 功能 | 为什么危险 |
|:--|:--|
| 引擎加载（Pyodide） | 失败 → 整个排版不可用，只剩轻量预览且复制被禁用 |
| `localStorage` 写入 | 隐私模式/配额满 → 草稿静默丢失（代码有 try/catch 但只返回 false） |
| Service Worker 更新 | 清单不同步 → 离线缺文件 / 更新拿不到新文件（`AGENTS.md` 明确列为坑） |
| 剪贴板写入 | 权限被拒 → 落到 `execCommand` 兜底，再失败则只剩提示 |
| 主题 JSON | 单套损坏 → 切到该主题时渲染抛错，预览停在上一次结果 |
