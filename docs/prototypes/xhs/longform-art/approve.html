01标题不再硬拆两行

你截图里的问题是：《桂花巷的黄昏》 8 个字被切成「《桂花巷的 / 黄昏》」， 右侧整片空白。根因是拆行按字数判断（旧规则：≤7 字才单行）， 且拆行用的字号（112px）与实际渲染字号（clamp 到 82px）不一致。

已改为按实际像素宽度判断：画布可用宽 888px，8 个中文字 @82px 只占 663px → 一行放得下，不再拆。 右侧空白由「标题只占半行」变成正常留白。

02去重后：183 套 → 23 张卡

原先把「行高 1.75 / 1.8 / 1.85 / 1.9」「h2 字重 600–900」「字距 0.02em vs 0.4px」 也算作不同格局 —— 这些在 1080 画布上肉眼分不出，却各占一张卡。 实测「居中素排·中标」9 张卡里，字号 / 标题对齐 / 标题装饰 全部相同。 现在只保留看得见的维度做签名：标题字号档 / 字族 / 标题对齐 / 标题装饰 / 明暗。

160 套纯换色的主题不再占卡位，全部降到对应卡片的配色变体里（下方 ④ 可切换）。 卡片总数：— 张，覆盖全部 183 套配色。

03排印差异

23 套 SVG 构图已全部删除。 原来的点阵网格、水平扫描线、半调网点、 拱门、八角星、同心圆这类原子图形，是设计素材站上到处都能见到的通行套路 —— 按你的要求「这种样式在网上看到过很多，就别用了，用我们自己原创的」，整套拿掉。

现在每张卡的差异只由排印本身产生：字号档 / 字族 / 行距 / 字距 / 正文对齐 / 标题对齐 / 标题装饰线 / 明暗。这些参数取自 183 套公众号主题的真实 JSON， 是排出来的，不是画上去的。另外只保留印刷品本来的语言：极淡纸纹 + 页脚细线 + 裁切角线。
需要你判断的取舍：删掉图形后，卡片之间的视觉差异会明显变小，整体更「素」。 这是「原创」的代价 —— 差异靠排版而非装饰。若觉得太素，可以再加「字体 / 栏宽 / 序号体系」 这类排印维度，而不是把图形加回来。
