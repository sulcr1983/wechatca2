## 一、结论摘要

1. **无 AI 自动排版：完全可行，且项目已有 80% 基础设施**。`core/preprocessor.py`（290 行纯正则）已覆盖纯文本 90% 结构识别；缺的三块（富文本粘贴转换、docx 导入、中英文排版规范）用三个成熟 MIT 库补齐，全部本地运行、零配置、不接 AI。
2. **用户流程重排为「粘贴 →（可选换风格）→ 复制」2-3 步**：默认主题就绪 + 输入即渲染 + 自动整理结果可见（解析条），选模板从"必经决策"降为"可选支线"。
3. **视觉重设计**：从"暖米+琥珀（咖啡馆感）"改为"暖纸灰阶 + 印泥朱砂点睛（编辑部感）"；顶栏/底栏/左栏改贴边白 chrome + 1px 分隔线；164 张色卡平铺改为"右栏最近使用条 + 模板库抽屉两级分组"。

## 二、无 AI 自动排版方案（需求 1）

### 2.1 现状资产（已验证）
- `core/preprocessor.py`：纯文本 → Markdown，识别代码块、序号标题（一、/1./(1)/①）、箭头并列→列表、孤立短行→小节标题、引号开头→引用块、首行自动大标题、`:::` 围栏模块穿透。
- 输入 400ms 防抖自动渲染；主题记忆/收藏/最近使用已存在。

### 2.2 补齐三件套（全部 MIT、本地 vendor、禁 CDN）

| 库 | 用途 | 引入方式 |
|---|---|---|
| **turndown**（10k★） | 粘贴的富文本（Word/网页/公众号复制）→ Markdown | `public/vendor/turndown.umd.js` |
| **mammoth.js** | .docx → HTML（浏览器端解析，无需外部二进制）→ turndown → Markdown | `public/vendor/mammoth.browser.min.js` |
| **pangu.js**（4.8k★） | 中英文间自动空格（盘古之白）——只进渲染管道，不进编辑器 | `public/vendor/pangu.min.js` |

### 2.3 三条输入路径
1. **纯文本粘贴/打字**：现有链路不变（preprocess + 渲染）。
2. **富文本粘贴**（默认开启）：paste 事件嗅探 `text/html` → turndown → 写回编辑器（光标置于末尾）→ 渲染。toast「已从富文本粘贴，自动转换为 Markdown」+ [撤销]（5s）。`Ctrl+Shift+V` 纯文本逃生门；`Ctrl+Z` 撤销（程序化写回必须压入原生撤销栈）。
3. **导入 .docx**：mammoth 解析 → 转 MD → 写回。编辑器非空时先弹确认层（替换/追加）。图片默认丢弃 + 占位行（见待决策项 D5）。

**编辑器内容形态 = 整理后的 Markdown 源码**：粘贴/导入/主动整理时写回（黑箱变白箱）；**手动打字时绝不改写用户文本**（防光标惊跳，R1 高风险项，上线前必须用 Word/网页/公众号三类真实富文本回归光标与撤销）。

## 四、信息架构与用户流程

### 4.1 页面骨架（三段式）

```
顶栏 56（白，底边 1px）   logo「版」+ SuperSu 排版 · tab（公众号排版/小红书封面）· 教程 · 设置
主区（左 620 白面板 | 1px 分隔 | 右 819 白面板）
  左栏：编辑器头部 48（内容从哪来：导入文档 / 清空 / +插入 / 看示例）
        编辑区（Markdown 源码，智能转换开关已迁出）
        结构解析条 44（on/off 双态）
  右栏：预览工具行 48（网页HTML | 手机预览 ······ 当前风格胶囊）
        预览舞台（#F7F4EE，手机页 375×min(760,100%)+内部滚动）
        风格条 104（最近使用胶囊横排 + 全部 164 套入口）
底栏 64（白，顶边 1px）   左：已保存/字数/结构完整 · 右：历史(ghost) → 推送草稿箱(secondary) → 复制(primary min-w148/h40)
```

### 4.2 主路径
**粘贴 → 复制（2 步）**。默认主题就绪（最近使用→内置默认）、输入即渲染、自动整理自动完成、复制按钮 Ctrl+Enter。典型路径：粘贴 → 看一眼解析条 → 复制（3 步）。

### 4.3 结构解析条（自动排版白盒化）
`[智能转换 switch] [识别结构] [大标题 ×1] [小节 ×2] [列表 ×1] [引用 ×1] …… [已自动整理 N 处] [整理格式 →]`
- 开关 on：朱砂 soft chip + track 朱砂；off：eye 图标 + dashed 边 + 灰文字
- chip 可点击跳转到编辑器对应位置；计数变化时 400ms 朱砂闪烁
- 空内容整条隐藏；识别项 >8 显示前 6 + 「还有 N 项」

### 4.4 模板选择衔接
- 当前风格胶囊常驻预览工具行右侧（3 色点 + 「素页 · 竹青」+ ▾），点击打开模板库抽屉
- 右栏底部「最近使用」胶囊横排（active = 白底朱砂边），一键切换
- 模板库抽屉 560px 右滑：搜索 + 两行 filter chips（全部/收藏/最近 + 六族）+ 2 列网格卡（64px 预览条 + 星标 + 「使用中」徽标 + 朱砂描边）

## 六、关键交互规范（落地必读）

### 6.1 Toast
- 深色 `#2A2721`、圆角 8、底部居中、max-w 480；结构 `[icon 16][text 13/1.5 #FFF][撤销 pill]`
- 撤销 pill：h24、圆角 999、transparent、1px rgba(255,255,255,.28)、#FFF 12/500
- 带 action 5s / 无 action 3s；双行 error toast（主行 13 #FFF + 次行 11 rgba(255,255,255,.62)）8s + [重试] pill
- 错误通道分工：**导入失败 = error toast；渲染失败 = 居中错误浮层**（帧5）
- 「已复制 ✓」「已推送 ✓」用 SVG check 图标（禁 Unicode ✓）

### 6.2 复制降级链（终点异常，帧4）
① `navigator.clipboard` ② 隐藏 contenteditable + `execCommand('copy')` ③ 手动复制指引浮层（打开时预览区 outline + 自动全选预览内容；Esc/遮罩/X 关闭；Clipboard API 恢复时同位置 info toast「现在可以直接自动复制了」）。

### 6.3 `+ 插入` popover
w280、圆角 14、padding 6、项高 44（图标 16 中性 + 名称 13，无描述）、输入类/结构类间 1px 分隔；选中项朱砂 soft + 朱砂文字；Esc/点外部关闭，焦点归还 `+ 插入`。11 项：大标题/二级标题/有序列表/无序列表/卡片组/要点总结/行动引导/关键数字/步骤流程/时间线/引文卡。

### 6.4 看示例 / 清空（编辑器顶部右侧）
两个独立入口（不并存单按钮状态机）：`清空` trash 图标按钮 32×32（仅非空可点，disabled = 描边 #E4E0D9 + 图标 #B9B2A6）+ `看示例` ghost-sm。示例灌入 = info toast「已载入示例文章」（不触发撤销 toast、不亮瞬态）；清空不用 toast，btn-demo 复位、解析条退化为未识别态。

### 6.5 docx 图片占位（D5）
 mammoth 忽略图片 + 段落连续占位合并为单个 4:3 占位框（dashed 描边 + 相机图标 + 「图片占位」）+ 右上角计数徽标；toast「文档含 N 张图片，已跳过——公众号图片需在素材库单独上传」。图片正则必须容错 pangu 空格：`^\[图片\s?\d+\]$`。

## 七、前端落地契约（同源复用，给 app.py 改造用）

1. **单函数双出口**：抽 `render_to_markdown(text) -> str` 与 `render_to_html(md, theme) -> str`；`/api/render` 与 `/api/ai-format` 共用；新增 `POST /api/markdown`（仅返回 markdown）。保持 `raw_text`/`theme_id` 入参名不变。
2. **pangu 只进渲染管道**：编辑器保留用户原文，复制产物正确、零侵入。
3. **图片占位映射**：转换器输出 `[图片N]` → `markdown_to_wechat_html()` 映射为 4:3 占位框 + 计数徽标。
4. **localStorage 键**：`supersu.theme.*`（记忆/收藏/最近）、`supersu.draft`（草稿，页面隐藏时存）、`supersu.history`（历史）。
5. **剪贴板三级降级链**（6.2）。
6. **粘贴拦截**：paste 事件嗅探 clipboardData 类型；程序化写回用 `execCommand('insertText')` 或 selection API 压入撤销栈。
