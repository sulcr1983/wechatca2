01一页看懂

项内容
给谁写公众号的个人作者（本项目主要用户＝苏哥本人，兼顾开源后的外部用户）
从哪开始在编辑器里写完 / 粘贴完一篇文章
要完成什么把这篇稿子「发出去或交出去」——公众号、小红书、朋友圈、存档交付
算完成目标平台的成品可以拿到手，且内容不失真（字没丢、图能显示、样式在）
现状缺口现在出口只有「复制富文本」一条；没有长图、没有文件导出、外链图到公众号会失效、主题不能自定义
30功能项（含扩展项）
6P0 必做
0新增外部依赖（P0 全部复用现有能力）
0新增后端要求（P0 纯前端可完成）
一句话策略：他们卖「素材量 + AI + 多人协作」；我们补「出口数量 + 内容保真 + 样式可控」。前者靠钱堆，后者靠工程。

02产品边界：守什么 / 不追什么

守住（我们的差异点，不能为了像他们而丢掉）

  • 纯本地 / 纯前端：文章不出浏览器；不做云端账号体系
  • 零 AI 也能出稿：AI 是可选加速器，不是必经之路
  • 免费 + 开源：不做会员付费墙、不做素材按次购买
  • 164 套自研主题：字号已对齐业界标尺，不做「数量军备竞赛」

不追（做了会毁掉立身之本）

  • AI 写作 / 仿写 / AI 标题：他们全押 AI；我们只保留 BYOK 可选
  • 几万套素材库：版权与设计成本黑洞，收益边际递减
  • 团队协作 / 多账号 / 数据分析 / 活码 / 批量回复：个人工具用不上，且必须后端 + 认证服务号
  • 定时群发：需微信认证服务号与后端常驻
  • H5 页面制作：那是秀米的另一条产品线，不是排版工具的事
关于 135 的 SVG 交互动效（唯一想追但不建议现在追的）：它之所以能活，是因为 135 走公众号 API 上传而不是复制粘贴——复制进公众号后台时微信会清洗标签，SVG / JS 全废。本项目本地版已有 /api/push 草稿箱推送这条路径，理论上可承载；但它是「一条新链路」而非一个前端小功能，且需要认证服务号 + IP 白名单。列入待定（见 §7）。

04P0 详解（6 项）

1. 长图导出

触发
点顶栏「导出」→ 选「长图 PNG」
处理
用当前主题渲染整篇 → 以 1080px 定宽输出竖版；高度超过 8000px 时分段再拼接
结果
弹出预览（可滚），给「下载 PNG」；文件名 标题-长图-YYYYMMDD.png
状态
渲染中显示进度；失败给原因（如画布超限）并建议改用 HTML 导出
边界
文章超过 5 万字时先提示「过长，建议分段」；空稿时按钮禁用

2. 导出 HTML 文件

触发
「导出」→「HTML 文件」
处理
用渲染结果拼一个自包含 HTML（样式已内联，图片尽量内嵌为 data URI）
结果
直接下载 .html，双击可看、可发给别人
边界
外链图未本地化时，导出内含外链并提示「对方网络可能看不到图」

3. 导出 PDF

触发
「导出」→「PDF」→ 选版式（窄版 手机阅读 / A4）
处理
调浏览器打印（只打印预览区），用户选「另存为 PDF」
结果
得到 PDF；窄版按手机宽度分页
边界
浏览器不支持打印时降级提示改用 HTML 导出

4. 导出 Word（.docx）

触发
「导出」→「Word」
处理
把渲染 HTML 按「标题/段落/列表/加粗/引用/代码」映射成 docx 结构；主题装饰（色块/背景）不还原
结果
下载 .docx；打开后层级正确、正文完整
边界
明确告知「Word 只保内容结构，不保主题视觉」，避免用户误期待

5. 导出 / 导入 Markdown

触发
「导出」→「Markdown」；或把 .md 拖进编辑区
处理
导出＝把引擎识别后的 Markdown 原样下载；导入＝读入编辑区（当纯文本处理，走同一套识别）
结果
导出 .md / 编辑区出现文件内容
边界
导入非 UTF-8 文件时提示编码问题，不静默乱码

6. 外链图本地化

触发
渲染时自动扫描；或用户点提示条上的「处理图片」
处理
列出正文里所有 http(s) 图片地址 → 能抓的转成内嵌数据；抓不到的（防盗链/跨域）标记保留
结果
提示条写明「N 张外链图，M 张已本地化、K 张需你手动上传」；本地化后复制到公众号可正常显示
边界
不静默失败：抓取失败必须写原因（CORS / 403 / 超时）；不得把占位文字当图片

07待定项

#待定为什么卡住
1SVG 交互动效需绑定「公众号 API 推送」链路（本地版有 /api/push），且需认证服务号 + IP 白名单；复制路径注定失效。要做需单独立项
2公众号文章链接采集纯前端跨域大概率失败，只能靠本地后端代理 [TBD]
3Word 导出的还原度边界只保结构 vs 尽力保视觉，需定一版 [TBD]
4长图最大像素上限浏览器画布有尺寸上限，超长文需分段策略，具体阈值待实测 [TBD]
5本地版与 PWA 的功能对齐范围导出类功能两版都做；带文件的（Word/zip）PWA 可做、本地版也可，需统一 [TBD]
