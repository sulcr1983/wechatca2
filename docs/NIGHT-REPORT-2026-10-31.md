## 一、你睡前说的两件事，都改了

### 1. 长图文：我上一轮方向又错了，已按**真实产品**重做

你说得对两次。第一次我把标题图的 12 套模板套到长文每一页；第二次我拆成「封面版式 + 内页风格」两个选择器 —— 这两个都是我自己拍脑袋，没去看别人怎么做。

**这轮去看了真实产品**（不是搜文章，是打开对方编辑器和 API 文档）：

**XHS-TextCard 的编辑器实际结构**：

```
模板与设置
├─ 内页 Tab
│   ├─ 内页模板      ← 12 选 1（只有这一处选模板）
│   ├─ 页面比例      ← 3 种，切换会重新分页
│   ├─ 内页背景图片
│   ├─ 排版基础（字号/行高/字距/内边距）
│   ├─ 标题层级      ← H1 2x / H2 1.35x / H3 1.15x
│   ├─ 字体族        ← 9 种
│   └─ 颜色风格      ← 背景/正文色/强调色（全局）
├─ 封面 Tab
│   ├─ 启用封面      ← 一个开关
│   ├─ 封面图片      ← 上传 / 随机
│   ├─ 封面字号      ← 48px
│   └─ 社交图标
└─ 导出 Tab
```

**关键：封面 Tab 里根本没有「版式选择」。** 它的 API 也只有一个 `template` 字段。

所以正确模型是：**模板选一次，管整套（封面 + 内页）。封面 = 这套模板的第 1 页。**

完整证据（含截图描述、API 文档原文、三条设计侧旁证）在
`docs/research-2026-10-31-xhs-longform-generators.md`。

**改完之后**：封面现在也有 EDITORIAL 刊头（和 P2 一样），底图只铺封面，内页纯色，整套 5 页同族。

### 2. 版式和尺寸的位置：全部搬到右栏了

你说「版式尺寸还是蛮重要的，有没有更好的位置」。我做了产品经理视角的走查，发现问题比「尺寸藏得深」更大：

| 原来 | 现在 |
|---|---|
| 版式、尺寸在右栏 | 版式、尺寸、字体、排法、色板 **全在右栏** |
| 字体、排法、色板在左侧折叠抽屉 | 按「先选结构 → 再微调观感」排 |
| **同一个「调外观」的动作被拆在屏幕两边** | 一处集中，不用左右来回找 |

右栏现在的顺序：**版式（12 选 1）→ 尺寸（3 选 1）→ 字体（4）→ 标题排法（3）→ 色板（8，带名字）**

左侧抽屉保留但默认收起，标题也从「调整版式/字体/尺寸」改成「字体 / 标题排法 / 色板」——
因为版式和尺寸已经不在那儿了，旧标题会让用户以为点开还有。

## 四、需要你决策的（3 件）

### 决策 1：长文模板要「跟随色板」还是「锁死配色」？

现在 12 套里有一半锁死了自己的配色（暗夜深思=深色、电影胶片=暗棕、星光=深蓝），
另一半跟随用户在左侧选的色板。

**问题**：如果用户选了「暗夜深思」模板，又去改色板，会发现色板不生效（因为模板锁了色）。
这可能让人困惑。

- 方案 A：保持现状（强风格模板锁色，其余跟随）
- 方案 B：全部跟随色板（那「暗夜深思」就不再是暗夜了）
- 方案 C：锁色时明确提示「这套模板自带配色」

### 决策 2：竞品有、我们暂时没有的四项，要不要补？

调研时看到的（都在 `docs/research-2026-10-31-xhs-longform-generators.md` §6）：

| 项 | 竞品做法 | 我们的状态 |
|---|---|---|
| 内页背景图 | 「图片将全屏铺满所有内页」 | 内页纯色 |
| 强制分页符 | `---` 独立成段即分页 | 我们把 `---` 当分隔线 |
| 水印 / 签名栏 | 高级设置里开关 | 无 |
| 页码开关 | 有 | 一直显示 |

### 决策 3：V6（保存按钮 Tab 顺序）还是没动

之前提过的：键盘用户按 Tab，会先碰到「保存」再碰到「换版式」。
要修得改桌面两栏的 DOM 结构，所以一直等你拍板。
